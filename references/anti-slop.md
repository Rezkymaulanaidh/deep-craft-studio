# Anti-Slop

Slop is text that survives editing because it sounds acceptable. Blacklists fail because the next draft invents a new variant. The durable defense is specificity: a sentence that carries information cannot be replaced by a generic one.

## 1. Four tests

Run these on every paragraph during the self-edit pass.

**Relocation test.** Could this sentence move to another document on the same topic unchanged? If yes, it carries no information about *this* subject. Cut it or replace it with a specific.

**Mechanism test.** For any causal claim, ask "how?". "The new process improved retention" is a conclusion. "Onboarding was cut from five days to one, and 30-day retention rose from 41% to 58%" is a mechanism with evidence. If you cannot state the mechanism, you do not yet understand the claim.

**Deletion test.** Delete the sentence. If the paragraph means the same thing, the sentence was decoration. Keep it deleted.

**Number test.** Any comparative or quantitative adjective ("significant", "substantial", "rapid", "many") must be replaced by a number, a range, or a named comparison. If no number exists, write "unquantified" and explain why.

## 2. Structural patterns

These are shapes, not phrases. They reappear with new vocabulary.

| Pattern | Tell | Fix |
|---|---|---|
| Not-X-but-Y seesaw | "This is not about tools, it is about culture." | State the claim directly: "Tooling changes rarely survive unchanged incentive structures." |
| Triad padding | Three parallel items where two would do, the third added for rhythm. | Keep the two that differ. Cut the echo. |
| One-line closer | Short punchy sentence ending every section, restating the point. | Delete. Let the evidence end the section. |
| Bold-label bullets | Every bullet opens with a bolded noun phrase. | Write sentences, or use a table when the content is genuinely tabular. |
| Heading echo | First sentence after a heading restates the heading. | Start with the finding. |
| Stakes inflation | "This is critical for success in today's landscape." | Name the consequence and who bears it. |
| Hedge stacking | "It could potentially be argued that perhaps..." | One hedge, or none. State confidence once. |
| False balance | Two sides presented as equal when the evidence is not equal. | Weight by evidence quality and say why. |
| Summary conclusion | Final paragraph repeats the introduction. | End with the implication, the open question, or the next action. |

## 3. Specificity upgrades

| Vague | Specific |
|---|---|
| "significantly improved performance" | "p95 latency fell from 840 ms to 210 ms on the same hardware" |
| "many users struggle with onboarding" | "38% of new accounts abandon setup before connecting a data source (n=1,204)" |
| "the library is widely used" | "14.2k GitHub stars, 2.1M weekly npm downloads" |
| "research shows that..." | "Smith et al. (2023, n=412) found..." |
| "best practices suggest" | "RFC 9110 section 9.3 requires..." |
| "in today's fast-paced environment" | delete |

## 4. Cadence

- Vary sentence length. A three-word sentence after a long one is emphasis; five long sentences in a row is a wall.
- Vary paragraph shape. Uniform three-sentence paragraphs read as generated.
- Prefer concrete nouns and active verbs. "The parser rejects malformed headers" beats "malformed headers are rejected by the parsing layer".
- Cut intensifiers: very, really, extremely, highly, incredibly, truly.
- One idea per paragraph. Two topics means two paragraphs.
- Read the first sentence of each paragraph in sequence. They should form a coherent outline. If they do not, the structure is broken, not the prose.

## 5. Smoke alarm list

Not exhaustive, and not the method. A hit means inspect the sentence around it.

delve, tapestry, testament to, game-changer, landscape (figurative), leverage (as a verb), robust (without a metric), seamless, unlock, empower, journey, at the end of the day, it is worth noting, in conclusion.

Treat a hit as a prompt to rewrite with specifics, not as an automatic ban. When the deliverable is not in English, build the equivalent list in that language; the four tests still apply.

## 6. Self-edit passes

1. **Structure pass.** Read headings and first sentences only. The argument should be visible. Fix order and gaps before line editing.
2. **Evidence pass.** For each claim, find the source or apply a label. Cut claims that cannot be supported.
3. **Line pass.** Apply the four tests, cut intensifiers, vary cadence, remove closers.

## 7. Overcorrection guard

Plain writing is not slop. Do not invent numbers, do not remove hedging from genuine uncertainty, and do not turn every sentence into a bullet. Specificity means true detail, not decoration with digits.
